# @amlplugins/amazon-bedrock

Native `@aws-sdk/client-bedrock-runtime` SDK re-exported under the `@amlplugins` namespace.

> Amazon Bedrock — managed foundation models (Claude, Llama, Mistral, Titan) with invoke and converse APIs.

## Install

```bash
npm install @amlplugins/amazon-bedrock
```

## Use

```ts
import { /* named exports from @aws-sdk/client-bedrock-runtime */ } from "@amlplugins/amazon-bedrock";
// or
import sdk from "@amlplugins/amazon-bedrock";
```

This package additionally re-exports `@aws-sdk/client-bedrock` under the `secondary` namespace.

Built and published by GitHub Actions on every push to `main`.

Part of the amlplugins family — see https://github.com/amlplugins.
